# AI Resume Analyzer

An AI-powered Resume Analyzer built using Flask and NLP techniques that compares resumes with job descriptions and generates a match score.

## Features

- Resume Upload (PDF)
-Job Description Matching
-Match Percentage Calculation
-Matched Skills Detection
- Missing Skills Detection
- Resume Improvement Suggestions
- Responsive Modern UI

---

### Frontend
- HTML
- CSS
- Bootstrap
- JavaScript

### Backend
- Python
- Flask

### NLP & AI
- TF-IDF Vectorization
- Cosine Similarity
- Skill Matching

### Libraries
- pdfplumber
- scikit-learn

---

## Project Workflow

1. Upload Resume
2. Extract Text from PDF
3. Clean & Process Text
4. Compare with Job Description
5. Calculate Similarity Score
6. Detect Missing Skills
7. Generate Suggestions
